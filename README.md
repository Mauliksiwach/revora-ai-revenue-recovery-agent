## 1. Product Overview

**Revora** is an AI-native revenue recovery agent built specifically with the **Razorpay AI Buildathon** in mind.

Traditional payment dashboards merely report failures *after* they happen. Revora acts as an active, bounded financial agent that answers the central merchant question:

> **"Can an AI agent help merchants recover revenue that would otherwise be lost because of failed payments, checkout abandonment, and issuer degradation?"**

The single core KPI of Revora is: **`REVENUE RECOVERED`**.

---

## 2. The Problem

In the Indian fintech ecosystem:
- Over **15%–25% of online payment attempts fail** due to a combination of issuer bank CBS downtime, NPCI switch congestion, customer authentication errors (OTP timeouts, incorrect MPIN), and drop-offs.
- Merchants lose **crores of rupees in preventable churn** because they treat every failure identically: either spamming retries immediately (causing customer fatigue and issuer throttling) or doing nothing.
- Lack of root-cause intelligence prevents merchants from knowing when an issuer is degraded versus when a customer merely needs a payment link.

---

## 3. The Revora Solution

Revora provides end-to-end autonomous revenue recovery through a 7-step bounded intelligence loop:

```text
Observe → Understand → Predict → Decide → Act Safely → Verify → Learn
```

1. **Observe**: Ingests real-time payment transactions across UPI, Cards, Netbanking, and Mandates.
2. **Understand (Revora Intelligence)**: Analyzes failure clusters and isolates root causes (e.g. 143 failures in 12 min → 91% issuer degradation).
3. **Predict (Recovery Probability Engine)**: Computes dynamic recovery scores based on customer history and failure code.
4. **Decide (Revora Agent)**: Selects the highest-ROI bounded action (`WAIT`, `RETRY`, `SEND_PAYMENT_LINK`, `SMART_SILENCE`, `ESCALATE_TO_HUMAN`).
5. **Act Safely (Policy Gate)**: Enforces merchant safety rules, cooldowns, and human approval gates for high-value transactions.
6. **Verify (Decision Timeline)**: Audits the exact recovery outcome.
7. **Learn**: Adjusts recovery probability weights based on verified recovery success.

---

## 4. Core Product Philosophy

- **Revenue Recovered over Vanity Metrics**: Transaction counts are secondary; the primary metric is actual rupees recovered.
- **Smart Silence (Signature Feature)**: Understanding that *sometimes the best recovery action is NO ACTION* (e.g., pausing outreach during an active bank outage).
- **Safety Gate**: The AI agent never has unrestricted financial authority; all actions pass through strict policy boundaries.
- **Indian Payment Context**: Built ground-up for UPI PSP switches, 3DS authentication, e-mandates, and multi-language outreach (English, Hindi, Hinglish).

## 6. Phase 1 Features: Revenue Command Center

Phase 1 establishes the rock-solid foundation for Revora:

- **Fintech SaaS Dashboard**:
  - High visual hierarchy KPI cards: **Revenue Processed (₹)**, **Revenue at Risk (₹)**, **Recovery Potential (₹)**, **Success Rate (%)**.
  - **Payment Failures & Volume Over Time** (Area chart tracking success vs failures across 2-hour rolling intervals).
  - **Payment Method Distribution** (UPI, Credit Card, Debit Card, Netbanking, Wallet, EMI).
  - **Top Failing Issuers / Banks** (HDFC, ICICI, SBI, AXIS with automated degradation alert badges).
  - **Failure Category Breakdown** (Issuer outages, 3DS auth, insufficient balance, checkout drop-offs).
- **Realistic Synthetic Payment Generator**:
  - Generates 1,200+ realistic transactions with Indian names, payment methods, weighted amounts, and an authentic **HDFC UPI Outage Spike Anomaly** to seed Phase 2 intelligence.
  - Interactive "Regenerate Dataset" capability.
- **Transaction Explorer & Failure Inspector**:
  - Search by Transaction ID, Customer, Order ID, or Failure Reason.
  - Filter by Status, Method, Bank, and Failure Category.
  - Sort by Amount, Retry Count, and Timestamp.
  - Slide-over **Transaction Detail Drawer** displaying full payment lifecycle, customer LTV, and raw gateway error payload.

## 7. Tech Stack

- **Frontend**: React 19, TypeScript, Vite 6, Tailwind CSS, Lucide React, Recharts.
- **Backend**: Node.js v20+, Express 4, TypeScript 5, Zod 3, Vitest 3, Supertest.
- **Database**: Supabase PostgreSQL + Resilient in-memory fallback.
- **Monorepo**: NPM Workspaces (`backend`, `frontend`).

---

## 8. Database Schema

The database schema (`database/schema.sql`) defines:
- `transactions`: Full transaction lifecycle, amount (INR), gateway codes, error payloads, retry counts.
- `customers`: Customer purchase history, lifetime value, preferred rail, preferred language.
- `incidents`: Scaffolding for Revora Intelligence (Phase 2).
- `recovery_decisions`: Scaffolding for Revora Agent & Policy Gate (Phase 4).
- `audit_logs`: Scaffolding for Decision Timeline (Phase 7).

## 9. Getting Started & Setup

### Prerequisites
- **Node.js**: v20.18.0 or later
- **npm**: 10.x or later
- **Git**

### Installation
```bash
# Clone the repository
git clone https://github.com/Mauliksiwach/revora-ai-revenue-recovery-agent.git
cd revora-ai-revenue-recovery-agent

# Install dependencies across all workspaces
npm install
```

### Environment Configuration
```bash
cp .env.example .env
```
*(No third-party keys are required to run out of the box — simulation mode is active by default)*
